# Чек-лист тестирования API /api/v2/orders

## GET /api/v2/orders

- Получение списка заказов возвращает 200 OK.
- При отсутствии заказов возвращается пустой массив.
- В ответе отсутствуют логически удалённые записи.
- Проверка структуры ответа.
- Проверка типов данных в ответе.
- Проверка работы без авторизации (401 Unauthorized).
- Проверка работы без необходимых прав (403 Forbidden).
- Проверка поведения при недоступности БД (500 Internal Server Error).

---

## GET /api/v2/orders/{id}

- Получение существующего заказа возвращает 200 OK.
- Получение несуществующего заказа возвращает 404 Not Found.
- Получение логически удалённого заказа возвращает 410 Gone.
- Проверка UUID некорректного формата (400 Bad Request).
- Проверка работы без авторизации (401 Unauthorized).
- Проверка работы без необходимых прав (403 Forbidden).
- Проверка поведения при недоступности БД (500 Internal Server Error).

---

## POST /api/v2/orders

- Создание заказа с валидными данными возвращает 201 Created.
- Проверка корректности созданной записи.
- Создание заказа с отсутствующими обязательными полями возвращает 400 Bad Request.
- Создание заказа с невалидными данными возвращает 400 Bad Request.
- Проверка работы без авторизации (401 Unauthorized).
- Проверка работы без необходимых прав (403 Forbidden).
- Проверка поведения при недоступности БД (500 Internal Server Error).

---

## PUT /api/v2/orders/{id}

- Обновление существующего заказа возвращает 200 OK или 204 No Content.
- Проверка сохранения изменений.
- Обновление несуществующего заказа возвращает 404 Not Found.
- Обновление логически удалённого заказа возвращает 410 Gone.
- Обновление с невалидными данными возвращает 400 Bad Request.
- Проверка UUID некорректного формата (400 Bad Request).
- Проверка работы без авторизации (401 Unauthorized).
- Проверка работы без необходимых прав (403 Forbidden).
- Проверка поведения при недоступности БД (500 Internal Server Error).

---

## DELETE /api/v2/orders/{id}

- Удаление существующего заказа возвращает 204 No Content.
- Повторное удаление заказа возвращает 410 Gone.
- Удаление несуществующего заказа возвращает 404 Not Found.
- Проверка UUID некорректного формата (400 Bad Request).
- Проверка работы без авторизации (401 Unauthorized).
- Проверка работы без необходимых прав (403 Forbidden).
- Проверка поведения при недоступности БД (500 Internal Server Error).
