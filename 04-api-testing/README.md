# Блок 4. Тестирование API

В данном разделе представлен чек-лист тестирования REST API контроллера `/api/v2/orders`.

Контроллер управляет жизненным циклом заказа и содержит методы:

- GET `/api/v2/orders`
- GET `/api/v2/orders/{id}`
- POST `/api/v2/orders`
- PUT `/api/v2/orders/{id}`
- DELETE `/api/v2/orders/{id}`
- HEAD `/api/v2/orders/{id}`

Цель блока: проверить корректность поведения API, HTTP-методов, статус-кодов, обработки ошибок валидации, прав доступа, несуществующих ID и технических сбоев.
