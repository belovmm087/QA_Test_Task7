# Граничные значения

## Вес груза

Поле имеет ограничение: максимум 20000 кг.

Проверки:

| Значение | Ожидаемый результат |
|-----------|-------------------|
| -1 | Ошибка валидации |
| 0 | Ошибка валидации |
| 1 | Успешно |
| 19999 | Успешно |
| 20000 | Успешно |
| 20001 | Ошибка валидации |

Почему критично:

Граничные ошибки часто возникают именно на максимальных и минимальных значениях. Некорректная обработка веса может привести к ошибкам расчёта стоимости перевозки.

---

## Объем груза

Поле имеет ограничение: максимум 82 м³.

Проверки:

| Значение | Ожидаемый результат |
|-----------|-------------------|
| -1 | Ошибка валидации |
| 0 | Ошибка валидации |
| 1 | Успешно |
| 81 | Успешно |
| 82 | Успешно |
| 83 | Ошибка валидации |

Почему критично:

Объем влияет на подбор транспорта и стоимость перевозки.

---

## Дата погрузки

Ограничение: нельзя выбирать прошедшую дату.

Проверки:

| Значение | Ожидаемый результат |
|-----------|-------------------|
| Вчера | Ошибка |
| Сегодня | Успешно |
| Завтра | Успешно |
| Через год | Успешно |

Почему критично:

Некорректная работа с датами приводит к невозможности оформления перевозки или к ошибкам планирования.

---

## Города отправления и назначения

Проверки:

| Значение | Ожидаемый результат |
|-----------|-------------------|
| Город найден в справочнике | Успешно |
| Несуществующий город | Ошибка |
| Пустое значение | Ошибка |
| Одинаковые города отправления и назначения | Ошибка |

Почему критично:

Ошибки в маршруте напрямую влияют на расчёт стоимости и возможность выполнения перевозки.

---

## Кнопка расчёта стоимости

Проверки:

| Состояние | Ожидаемый результат |
|-----------|-------------------|
| Все поля заполнены корректно | Выполняется запрос |
| Есть незаполненные обязательные поля | Запрос не выполняется |
| Маршрут отсутствует | Отображается ошибка |
| Ошибка API | Отображается сообщение об ошибке |

Почему критично:

Кнопка запускает основной бизнес-процесс формы и интеграцию с расчётным сервисом.
