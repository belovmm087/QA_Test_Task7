# Сырой ответ AI

Источник: Google Gemini

## Чек-лист тестирования формы создания заявки на перевозку

### 1. Позитивные сценарии (Positive Cases)

- [ ] Успешное заполнение всех полей валидными данными (выбор городов из списка, вес и объем в пределах нормы, дата — завтрашний день) и нажатие «Рассчитать стоимость».
- [ ] Поиск города отправления через автокомплит по части имени (например, «Мос» -> «Москва»).
- [ ] Поиск города назначения через автокомплит по части имени.
- [ ] Корректный выбор города отправления напрямую из раскрывающегося справочника.
- [ ] Корректный выбор города назначения напрямую из раскрывающегося справочника.
- [ ] Выбор текущей даты в календаре (если бизнес-логика позволяет отгрузку «день в день»).
- [ ] Выбор будущей даты в календаре (например, +1 день, +1 месяц, +1 год).

### 2. Граничные значения (Boundary Value Analysis - BVA)

#### Вес груза (Лимит: 20 000 кг)

- [ ] Минимальное валидное значение: 1 (или 0.1, если разрешены дробные).
- [ ] Максимальное валидное значение: 20000.
- [ ] Значение чуть ниже максимума: 19999.
- [ ] Значение чуть выше максимума (негативное): 20001.
- [ ] Нулевое значение (негативное): 0.

#### Объем груза (Лимит: 82 м³)

- [ ] Минимальное валидное значение: 1 (или 0.1, если разрешены дробные).
- [ ] Максимальное валидное значение: 82.
- [ ] Значение чуть ниже максимума: 81.9.
- [ ] Значение чуть выше максимума (негативное): 82.1 или 83.
- [ ] Нулевое значение (негативное): 0.

### 3. Валидация полей и негативные проверки

- [ ] Отправка формы с пустыми обязательными полями.
- [ ] Ввод отрицательных значений в поля веса и объема.
- [ ] Ввод нечисловых символов.
- [ ] Ввод спецсимволов или скриптов в поля автокомплита городов.
- [ ] Выбор прошедшей даты.
- [ ] Ручной ввод прошедшей даты.
- [ ] Ввод несуществующего города.

### 4. Интеграционные проверки

- [ ] Проверка корректного POST-запроса.
- [ ] Проверка отображения стоимости.
- [ ] Обработка ошибки «Маршрут не найден».
- [ ] Обработка 500 Error и Network Timeout.

### 5. UX/UI

- [ ] Проверка плейсхолдеров и единиц измерения.
- [ ] Проверка отображения ошибок валидации.
- [ ] Проверка отображения лоадера.
- [ ] Проверка навигации с клавиатуры.
- [ ] Проверка адаптивности интерфейса.
- [ ] Проверка сброса стоимости после изменения данных маршрута.
