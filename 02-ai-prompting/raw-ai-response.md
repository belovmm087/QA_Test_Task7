# Сырой ответ AI

## Позитивные проверки

- Выбор города отправления из списка.
- Выбор города назначения из списка.
- Ввод корректного веса груза.
- Ввод корректного объема груза.
- Выбор будущей даты погрузки.
- Успешный расчет стоимости перевозки.

## Негативные проверки

- Пустой город отправления.
- Пустой город назначения.
- Отсутствие веса груза.
- Отсутствие объема груза.
- Отсутствие даты погрузки.
- Маршрут не найден.

## Граничные значения

### Вес груза

- 0 кг
- 1 кг
- 19999 кг
- 20000 кг
- 20001 кг

### Объем груза

- 0 м³
- 1 м³
- 81 м³
- 82 м³
- 83 м³

## Проверки UX

- Корректное отображение формы.
- Удобство выбора даты.
- Наличие сообщений об ошибках.

## Проверки API

- Успешный ответ API.
- Ошибка API.
- Таймаут API.
