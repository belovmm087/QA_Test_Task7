# Prompt для генерации чек-листа

Ты выступаешь в роли Senior QA Engineer.

Необходимо подготовить полный чек-лист тестирования формы создания заявки на перевозку.

Контекст:

Форма содержит следующие поля:

1. Город отправления
- автокомплит
- выбор из справочника городов

2. Город назначения
- автокомплит
- выбор из справочника городов

3. Вес груза
- числовое поле
- единица измерения кг
- максимальное значение 20000

4. Объем груза
- числовое поле
- единица измерения м³
- максимальное значение 82

5. Дата погрузки
- выбор через календарь
- прошедшую дату выбирать нельзя

6. Кнопка «Рассчитать стоимость»
- отправляет POST-запрос в API
- API возвращает стоимость перевозки в рублях
- либо ошибку «Маршрут не найден»

Необходимо сформировать:

- позитивные проверки
- негативные проверки
- проверки валидации
- проверки граничных значений
- проверки UX
- проверки интеграции с API

Результат оформить в виде структурированного чек-листа.
