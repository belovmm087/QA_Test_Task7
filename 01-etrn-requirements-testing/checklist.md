# Чек-лист проверки ЭТрН

## Титул 1. Создание и отправка ЭТрН грузоотправителем

1. Создание новой ЭТрН.
2. Заполнение обязательных сведений первого титула.
3. Заполнение данных грузоотправителя.
4. Заполнение данных перевозчика.
5. Заполнение данных грузополучателя.
6. Заполнение данных водителя.
7. Заполнение сведений о грузе.
8. Заполнение сопроводительных документов.
9. Сохранение ЭТрН как черновика.
10. Подписание и отправка первого титула.
11. Установка статуса «Ожидает отгрузки со склада».

## Передача через оператора ЭДО

1. Отправка первого титула через оператора ЭДО.
2. Получение первого титула перевозчиком.
3. Корректная маршрутизация сообщения оператором ЭДО.
4. Обработка ошибки доставки сообщения.
5. Повторная отправка документа после ошибки.

## Титул 2. Погрузка и перевозка

1. Подтверждение получения первого титула перевозчиком.
2. Передача информации о погрузке.
3. Проверка наличия замечаний при погрузке.
4. Внесение замечаний при погрузке.
5. Отправка второго титула.
6. Генерация QR-кода.
7. Получение QR-кода водителем.
8. Установка статуса «Груз принят к перевозке».

## Титул 3. Приёмка груза грузополучателем

1. Получение второго титула грузополучателем.
2. Ожидание транспортного средства на месте разгрузки.
3. Прибытие транспортного средства на разгрузку.
4. Подтверждение приёмки груза.
5. Проверка сценария отказа от приёмки груза.
6. Внесение данных о приёмке.
7. Подписание и отправка третьего титула.
8. Установка статуса «Груз принят грузополучателем».

## Титул 4. Выгрузка груза

1. Получение сведений о разгрузке.
2. Проверка наличия замечаний при выгрузке.
3. Внесение замечаний при выгрузке.
4. Отправка данных о выгрузке.
5. Подписание и отправка четвёртого титула.
6. Передача четвёртого титула участникам перевозки.
7. Отправка сведений в ГИС ЭПД.

## Завершение процесса

1. Получение четвёртого титула грузоотправителем.
2. Получение четвёртого титула перевозчиком.
3. Получение четвёртого титула грузополучателем.
4. Установка статуса ЭТрН «Завершён».
5. Проверка корректности финального статуса документа.
6. Проверка истории действий и подписаний.
7. Проверка сохранности всех титулов документа.
