Чек-лист проверки ЭТрН

Титул 1. Создание и отправка ЭТрН грузоотправителем

1. Создание новой ЭТрН.
2. Заполнение обязательных сведений первого титула.
3. Заполнение данных грузоотправителя.
4. Заполнение данных перевозчика.
5. Заполнение данных грузополучателя.
6. Заполнение данных водителя.
7. Заполнение сведений о грузе.
8. Заполнение сопроводительных документов.
9. Сохранение ЭТрН как черновика.
10. Подписание и отправка первого титула.
11. Установка статуса «Ожидает отгрузки со склада».

Передача через оператора ЭДО

1. Отправка первого титула через оператора ЭДО.
2. Получение первого титула перевозчиком.
3. Рассылка первого титула всем участникам процесса.
4. Обработка ошибки отправки титула.
5. Повторная отправка титула после ошибки.

Погрузка и титул 2

1. Подтверждение получения первого титула перевозчиком.
2. Контроль погрузки водителем.
3. Передача данных о погрузке диспетчеру.
4. Проверка сценария без замечаний по погрузке.
5. Проверка сценария с замечаниями по погрузке.
6. Активация чекбокса «Замечания при погрузке».
7. Заполнение поля несоответствия.
8. Подписание и отправка второго титула.
9. Установка статуса «Груз принят к перевозке».

Разгрузка и титул 3

1. Генерация и отправка QR-кода водителю.
2. Прибытие водителя на место разгрузки.
3. Получение второго титула грузополучателем.
4. Принятие транспорта на разгрузку.
5. Проверка сценария принятия груза.
6. Проверка сценария отказа от принятия груза.
7. Активация чекбокса «Груз принят».
8. Заполнение данных о приемке.
9. Подписание и отправка третьего титула.
10. Установка статуса «Груз принят грузополучателем».

Выгрузка и титул 4

1. Получение третьего титула перевозчиком.
2. Ожидание разгрузки.
3. Получение сведений о разгрузке.
4. Проверка сценария без замечаний по выгрузке.
5. Проверка сценария с замечаниями по выгрузке.
6. Активация чекбокса «Замечания при выгрузке».
7. Заполнение поля несоответствия.
8. Подписание и отправка четвертого титула.
9. Рассылка четвертого титула участникам процесса.
10. Установка финального статуса «Завершен».

Валидации и ошибки

1. Попытка сохранить ЭТрН без обязательных полей.
2. Попытка подписать титул без обязательных данных.
3. Попытка перейти к следующему титулу без подписи предыдущего.
4. Проверка некорректного формата ИНН.
5. Проверка некорректного формата даты.
6. Проверка пустых сведений о грузе.
7. Проверка отсутствия сопроводительных документов.
8. Проверка повторной отправки уже подписанного титула.
9. Проверка доступа к действиям по ролям.
10. Проверка отображения ошибки пользователю.
