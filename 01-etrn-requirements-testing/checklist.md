# Чек-лист проверки ЭТрН

## Создание документа

- Создание новой ЭТрН
- Сохранение черновика
- Открытие сохранённого черновика
- Редактирование черновика
- Удаление черновика

## Проверка реквизитов

- Заполнение обязательных полей
- Проверка заполнения ИНН
- Проверка заполнения КПП
- Проверка заполнения данных грузоотправителя
- Проверка заполнения данных перевозчика
- Проверка заполнения данных грузополучателя
- Проверка заполнения информации о грузе
- Проверка заполнения данных транспортного средства
- Проверка заполнения данных водителя

## Валидация данных

- Попытка сохранения пустого документа
- Ввод некорректного ИНН
- Ввод некорректного КПП
- Ввод специальных символов в числовые поля
- Проверка максимальной длины полей
- Проверка обязательности реквизитов

## Статусы документа

- Переход в статус «Черновик»
- Переход в статус «Подписан»
- Переход в статус «Отправлен»
- Переход в статус «Принят»
- Переход в статус «Отклонён»
- Проверка отображения текущего статуса

- Отображение ошибок валидации
- Ошибка отправки документа
- Ошибка подписания документа

- Корректность уведомлений при смене статуса
