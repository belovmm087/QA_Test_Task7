# Тест-кейсы ЭТрН

## TC-001 Создание ЭТрН с обязательными полями

Предусловие: пользователь авторизован.

Шаги:
1. Создать новую ЭТрН.
2. Заполнить обязательные поля.
3. Нажать «Сохранить».

Ожидаемый результат:
Документ успешно создан и сохранён.

---

## TC-002 Попытка создания ЭТрН без обязательных полей

Предусловие: пользователь авторизован.

Шаги:
1. Создать новую ЭТрН.
2. Не заполнять обязательные поля.
3. Нажать «Сохранить».

Ожидаемый результат:
Документ не сохраняется. Пользователь получает сообщение о незаполненных обязательных полях.

---

## TC-003 Изменение статуса ЭТрН

Предусловие: существует созданная ЭТрН.

Шаги:
1. Открыть документ.
2. Выполнить действие для смены статуса.

Ожидаемый результат:
Статус документа изменяется согласно бизнес-процессу.

---

## TC-004 Проверка отображения реквизитов

Предусловие: существует созданная ЭТрН.

Шаги:
1. Открыть документ.
2. Проверить реквизиты участников перевозки.

Ожидаемый результат:
Все реквизиты отображаются корректно и соответствуют введённым данным.

---

## TC-005 Ошибка при вводе некорректного ИНН

Предусловие: создание новой ЭТрН.

Шаги:
1. Указать некорректный ИНН.
2. Попытаться сохранить документ.

Ожидаемый результат:
Система отображает ошибку валидации и не позволяет сохранить документ.
