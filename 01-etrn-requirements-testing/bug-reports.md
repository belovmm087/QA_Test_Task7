# Баг-репорты ЭТрН

## BUG-001 Отправка второго титула без заполнения сведений о погрузке

### Severity
High

### Предусловие
Первый титул успешно отправлен перевозчику.

### Шаги воспроизведения

1. Авторизоваться под ролью перевозчика.
2. Открыть полученную ЭТрН.
3. Не заполнять сведения о погрузке.
4. Нажать «Подписать и отправить второй титул».

### Фактический результат

Система позволяет подписать и отправить второй титул.

### Ожидаемый результат

Система должна запретить отправку второго титула и отобразить сообщение о незаполненных обязательных данных.

## BUG-002 Документ получает статус «Завершён» без формирования четвёртого титула

### Severity
Critical

### Предусловие
Третий титул успешно отправлен грузополучателем.

### Шаги воспроизведения

1. Завершить процесс приёмки груза.
2. Не формировать четвёртый титул.
3. Проверить текущий статус ЭТрН.

### Фактический результат

Документ получает статус «Завершён».

### Ожидаемый результат

Документ должен оставаться в промежуточном статусе до успешного формирования и отправки четвёртого титула.

## BUG-003 Отсутствует отображение замечаний при выгрузке у грузоотправителя

### Severity
Medium

### Предусловие
При выгрузке указаны замечания.

### Шаги воспроизведения

1. Создать ЭТрН.
2. Пройти процесс до этапа выгрузки.
3. Указать замечания при выгрузке.
4. Завершить процесс.
5. Открыть документ под ролью грузоотправителя.

### Фактический результат

Замечания при выгрузке не отображаются.

### Ожидаемый результат

Замечания должны отображаться всем участникам процесса, имеющим доступ к документу.
