# Запрос для получения актуальной стоимости доставки

## Задача

Необходимо получить актуальную стоимость доставки по параметрам:

- дата заказа;
- тип клиента;
- общий вес.

При выборе цены нужно учитывать:

- запись с максимальным периодом, который меньше или равен дате заказа;
- тип клиента;
- весовой интервал;
- границу веса: если вес равен верхней границе интервала, должен выбираться интервал `до`, а не следующий интервал `от`;
- если вес больше максимального известного интервала, стоимость не определена.

## Псевдокод запроса 1С

```1c
Запрос = Новый Запрос;

Запрос.Текст =
"ВЫБРАТЬ ПЕРВЫЕ 1
|   ЦеныДоставки.Стоимость КАК Стоимость
|ИЗ
|   РегистрСведений.ЦеныДоставки КАК ЦеныДоставки
|ГДЕ
|   ЦеныДоставки.ТипКлиента = &ТипКлиента
|   И ЦеныДоставки.Период <= &ДатаЗаказа
|   И ЦеныДоставки.ВесОт < &ОбщийВес
|   И &ОбщийВес <= ЦеныДоставки.ВесДо
|УПОРЯДОЧИТЬ ПО
|   ЦеныДоставки.Период УБЫВ";

Запрос.УстановитьПараметр("ТипКлиента", ТипКлиента);
Запрос.УстановитьПараметр("ДатаЗаказа", ДатаЗаказа);
Запрос.УстановитьПараметр("ОбщийВес", ОбщийВес);

Результат = Запрос.Выполнить();

Если Результат.Пустой() Тогда
    Возврат NULL;
КонецЕсли;

Выборка = Результат.Выбрать();
Выборка.Следующий();

Возврат Выборка.Стоимость;
```

## Пояснение логики

Условие `ЦеныДоставки.Период <= &ДатаЗаказа` выбирает только те записи, которые уже действовали на дату заказа.

Сортировка `Период УБЫВ` позволяет сначала получить самую свежую актуальную запись.

`ВЫБРАТЬ ПЕРВЫЕ 1` ограничивает результат одной записью.

Для веса используется условие:

```1c
ЦеныДоставки.ВесОт < &ОбщийВес
И &ОбщийВес <= ЦеныДоставки.ВесДо
```

Такой подход исключает пересечение интервалов.

Например, если есть интервалы:

- до 10;
- от 10 до 20;

то вес `10` должен попасть в первый интервал, где верхняя граница равна `10`, а не во второй.

Если подходящей записи нет, метод возвращает `NULL`, потому что стоимость доставки не определена.
