# Блок 5. Базовые вопросы по 1С

В данном разделе рассмотрена задача расчёта актуальной стоимости доставки по регистру сведений «Цены доставки».

Блок включает:

- запрос на языке запросов 1С или псевдокод для выбора актуальной стоимости доставки;
- обработку даты заказа, типа клиента и общего веса;
- проверку граничных значений веса;
- анализ ошибок в предложенной реализации метода `РассчитатьСтоимость`;
- предложения по исправлению найденных проблем.

Цель блока: показать понимание базовой логики работы с регистрами сведений 1С, отбора актуальной записи по периоду, обработки весовых интервалов и анализа потенциальных дефектов в коде.
