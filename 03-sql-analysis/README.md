# Блок 3. Анализ данных SQL

В данном разделе представлены SQL-запросы на PostgreSQL для решения задач по анализу данных:

1. Поиск второй по величине уникальной зарплаты.
2. Поиск дублирующихся email-адресов.
3. Поиск клиентов без заказов.

Цель блока: показать понимание базовых SQL-операций, работы с уникальными значениями, агрегацией, группировкой и соединением таблиц.
