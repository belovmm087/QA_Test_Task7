# Объяснение решений SQL

## Задача 1. Вторая по величине уникальная зарплата

Используется DISTINCT для исключения повторяющихся значений зарплаты.

Сортировка выполняется по убыванию зарплаты.

OFFSET 1 пропускает максимальную зарплату, а LIMIT 1 возвращает следующую за ней запись.

Если второй уникальной зарплаты не существует, подзапрос возвращает NULL.

---

## Задача 2. Поиск дублирующихся email

Данные группируются по полю email с помощью GROUP BY.

Функция COUNT(*) подсчитывает количество записей в каждой группе.

Условие HAVING COUNT(*) > 1 позволяет вернуть только те email-адреса, которые встречаются более одного раза.

---

## Задача 3. Клиенты без заказов

Используется LEFT JOIN между таблицами Customers и Orders.

Такой тип соединения позволяет получить всех клиентов независимо от наличия заказов.

Если заказов нет, поля таблицы Orders содержат NULL.

Условие WHERE o.id IS NULL оставляет только клиентов, которые не имеют связанных заказов.
